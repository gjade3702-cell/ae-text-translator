# AE Text Translator — AE 批量文本翻译脚本

[English](README.en.md) · **v2.0.17** · MIT License

一个 Adobe After Effects 脚本：选中文本图层，输入目标语言，脚本批量复制图层并调用大模型逐层翻译文字，支持父子级 / 遮罩关系修复与可选预合成。

## 功能特性

- **批量多语言翻译**：一次选中多个图层，同时翻译成多种语言
- **结构自动修复**：父子级重映射、遮罩完整性检查（漏选遮罩层会提前提示）
- **通用 API**：支持任意 OpenAI / Anthropic 兼容接口，默认 DeepSeek V4
- **按行翻译**：多行文本逐行翻译并保持行数
- **可靠性**：失败自动重试、实时进度、CSV 日志导出
- **记忆与安全**：设置自动记忆；API Key 混淆存储，脚本文件内不含任何 Key

## 安装

1. 将 `AE-Text-Translator.jsxbin` 放入 ScriptUI Panels 目录：

   ```
   C:\Program Files\Adobe\Adobe After Effects <版本>\Support Files\Scripts\ScriptUI Panels\
   ```

2. 在 AE 中打开：
   - **文件 → 脚本 → 运行脚本文件…** 选择该文件（一次性运行）；或
   - **窗口 → 扩展** 打开该面板（常驻使用，推荐）
3. 点右上角「设置」→ 填 API Key、选模型 → 点「测试连接」验证。

> 本仓库发布 `.jsxbin`（ExtendScript 二进制编码）版本，便于直接使用。

## 快速开始

1. 打开合成，选中要翻译的文本图层（可同时选中父层与子层）。
2. 输入目标语言，逗号 / 顿号分隔，可用：中文名（`英语`）、英文名（`English`）、语言代码（`EN`）。
3. 点「开始处理」。每个语言生成一批副本图层；勾选「自动预合成」时，每个语言打包成一个以语种名命名的合成。

## 设置

| 设置 | 说明 |
| --- | --- |
| API 协议 | OpenAI 兼容（`Bearer`，`/chat/completions`）/ Anthropic 兼容（`x-api-key`，`/v1/messages`） |
| API 地址 / Key | 默认 DeepSeek；可填任意 OpenAI / Anthropic 兼容端点；Key 以掩码显示 |
| 模型 | 自由填写，或点「获取模型」从 API 拉取列表选择。DeepSeek 用 `deepseek-v4-flash` / `deepseek-v4-pro` |
| 禁用思考模式 | DeepSeek V4 默认开启思考，翻译建议关闭（默认勾选） |
| 超时 / 重试 / 间隔 | 单请求超时、失败重试次数、请求间隔（防限流） |
| 提示词 / 界面语言 | 自定义翻译提示词；中 / 英界面切换 |
| 目标语言 | 内置 44 种常见语言字典，中文名 / 英文名 / 代码均可识别 |

## 注意事项

- **安全**：Key 以混淆形式存入 AE 设置（非强加密），建议单独申请 Key 并设置用量上限，勿在公共电脑使用。
- **费用**：接口按 token 计费（DeepSeek 以官方定价为准），翻译前留意字符量确认框。
- **处理中界面冻结**：为可靠起见采用同步执行，处理期间界面无响应、无法取消，请等待完成。
- **遮罩关系**：若某图层带遮罩，需连同其上层遮罩层一起选中，否则会丢失遮罩。
- **撤销**：整个翻译过程是一个 Undo 组，`Ctrl+Z` 一次撤销全部语言副本。
